# BotLocker Troubleshooting Guide

If the dashboard is blank or bans aren't appearing, check these common points.

## 1. Dashboard & Reports
The dashboard is a "passive" viewer. It reads text files generated by root.
- **Path:** `/var/www/vhosts/YOUR_DOMAIN/bot_report.txt`
- **Issue:** If this file is missing, the cronjob hasn't run or failed.
- **Fix:** Run the report manually: `sudo /usr/local/sbin/botlocker-top10-report`

## 2. IPSet & Firewall Integrity
BotLocker uses the Linux Kernel `ipset` to manage thousands of IPs without slowing down the server.
- **Check the List:** `sudo ipset list botlocker_trap`
- **Check the Rule:** `sudo iptables -L INPUT -n --line-numbers`
  *The BotLocker rule MUST be at position 1 or 2 to work.*

## 3. Log Path Issues
If BotLocker isn't catching anyone, the log paths in `botlocker.conf` might be wrong for your OS.
- **Ubuntu/Plesk:** `/var/www/vhosts/system/*/logs/*`
- **Standard Nginx:** `/var/log/nginx/*.log`
- **Test:** Run `ls /your/path/here` to see if the script can actually "see" the logs.

## 4. Emergency Unban
Locked yourself out? 
1. Log in from a different IP or via your VPS console.
2. Add your remote IP to `/etc/botlocker/conf.d/admin-access.conf`.
3. Run `sudo ipset flush botlocker_trap`.
